# CivicFix - Hackathon Presentation

## SLIDE 1 — THE PROBLEM
**Civic problems are easy to see. Reporting them isn't.**

People encounter issues every day:
* garbage accumulation
* potholes
* broken streetlights
* damaged roads
* blocked drains

But turning a visual problem into a structured, actionable report for the city can require unnecessary manual effort. It shouldn't take a manual to report a pothole.

---

## SLIDE 2 — THE SOLUTION
# CivicFix
### Spot it. Report it. Fix it.

**The Core Flow:**
```text
📷 Photo
   ↓
🤖 AI understands the issue
   ↓
✍️ User verifies the report
   ↓
📍 Location
   ↓
📋 Structured civic report
   ↓
📊 Track resolution
```
*Citizens don't need to understand the reporting system. They simply show the problem.*

 ↓

 ↓

**Technical Highlights:**
* Multimodal AI (MVP simulation)
* Structured JSON output validation
* Client-side canvas image compression to optimize payloads
* Server-side API operations for secure processing
* Persistent report tracking
