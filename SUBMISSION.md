Project Name:
CivicFix

Tagline:
Spot it. Report it. Fix it.

Problem:
Civic issues like potholes, illegal dumping, and broken streetlights are everywhere, but reporting them is tedious and confusing. Citizens often don't know the proper department to contact or the formal language to use, resulting in a high barrier to civic engagement.

Solution:
CivicFix eliminates the friction of civic reporting. Users simply take a photo of the problem, and CivicFix uses AI to automatically categorize, assess severity, and structure the report for municipal authorities.

Key Features:
- Instant AI-powered issue detection from photos.
- Automatic severity classification (Low, Medium, High).
- AI-generated formal descriptions and recommended actions.
- Manual location tagging or browser geolocation.
- Real-time report tracking via unique IDs.
- Community impact dashboard visualizing city-wide resolution metrics.

Technology:
- Next.js 14 (App Router)
- React
- Tailwind CSS & shadcn/ui
- TypeScript
- Client-side Canvas Image Compression
- Server Actions
- Vercel

AI Usage:
CivicFix uses Vision AI to analyze user-uploaded images. The AI identifies the civic issue, categorizes it (e.g., Waste, Pothole, Streetlight), determines its severity, and drafts a structured description for municipal review. Users retain the ability to edit AI-generated fields before submission.

Impact:
CivicFix empowers citizens to take action in seconds. By providing structured, standardized data to municipalities, it drastically reduces triage time and helps cities resolve infrastructure issues faster.

Future Scope:
- Direct integrations with municipal 311 APIs.
- Automated routing to specific city departments based on AI categorization.
- Multilingual reporting (users type in native language, AI standardizes for the city).
- Geographic issue heatmaps for long-term city planning.
