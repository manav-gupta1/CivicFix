# CivicFix Demo Script

*The demo should take approximately 60–90 seconds.*

### 0–10 sec: Landing Page
- Open the landing page (`https://civicfix-demo.vercel.app`).
- **Say**: *"CivicFix turns everyday civic problems into structured, trackable reports using AI."*

### 10–25 sec: Report a Problem
- Click **Report a Problem**.
- Click the "Try Demo Report" button (or upload a demonstration image).
- Show the staged "Analyzing image..." AI loading sequence.

### 25–40 sec: Review AI Analysis
- **Show**: The detected issue (Roadside garbage accumulation), severity (High), AI confidence (94%), and the generated description.
- **Explain**: Highlight how the user doesn't have to write a formal complaint—the AI structures the data perfectly for municipal workers. Point out the transparency note ensuring users can edit the data if needed.

### 40–55 sec: Location & Submission
- Click **Confirm & Continue**.
- Confirm the location ("Yamuna Vihar, Delhi").
- Click **Submit Report**.
- Wait for the success screen.
- **Show**: The generated report ID (`CF-XXXXX`) and copy it to the clipboard.

### 55–70 sec: Tracking Page
- Click **Track Report** to open the tracking page.
- **Show**: The clear timeline interface.
```text
Submitted
→ Assigned
→ In Progress
→ Resolved
```
- Explain how this creates transparency and trust between citizens and authorities.

### 70–90 sec: Dashboard
- Click **Dashboard** in the top navigation.
- **Show**: The community metrics, the "127 Total Reports" count, and the charts.
- **Explain**: Explain how this data gives municipalities a bird's-eye view of civic health, and how the same system can scale across neighborhoods and cities.
