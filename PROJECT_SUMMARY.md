Project:
CivicFix

Tagline:
Spot it. Report it. Fix it.

Problem:
Civic problems like garbage dumping and potholes are highly visible but notoriously hard to report. Navigating municipal systems and correctly describing issues causes high friction, leaving many problems unreported and unresolved.

Solution:
CivicFix eliminates reporting friction by turning a simple photo into a structured, actionable civic report. The user simply takes a picture, verifies the AI-extracted details and location, and submits.

Target Users:
Everyday citizens looking to improve their neighborhoods, and municipalities/NGOs seeking standardized, triaged infrastructure data.

Core Technology:
Next.js 14, React, Tailwind CSS, TypeScript, Client-Side Canvas Image Compression, and Server Actions.

AI Component:
CivicFix uses Vision AI to analyze uploaded photos, automatically determining the issue category, severity level, and generating a formal description. This structures unstructured visual data into a standardized JSON format.

Key Innovation:
Shifting the burden of data entry from the citizen to the machine. The citizen provides the visual context; the AI provides the structured data.

Current MVP:
A fully functional, mobile-responsive web app featuring client-side image compression, simulated AI issue detection, manual user verification, location tagging, persistent report tracking via unique IDs, and a community impact dashboard.

Potential Impact:
Empowers citizens to engage in local governance in under 30 seconds while drastically reducing triage and dispatch times for city operations.

Future Scope:
Direct integrations with municipal 311 systems, automated department routing based on AI categorization, duplicate issue detection via geographic proximity, and multilingual support.
